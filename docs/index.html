它现在能做什么

Features / 01—04

01 / 解析

说人话就能记

「午饭 28，晚上和朋友吃了 200」直接拆成两笔，金额、分类、日期自动填好，再确认一次即可入账。

02 / 截图

账单截图能读

微信、支付宝账单截图直接识别，多条交易分行提取，自动过滤「消息数」「合计」「按钮文案」这类噪音。

03 / 统计

看得清钱去哪了

按日期区间、分类、收/支筛选，实时汇总笔数与合计；数字会滚动到位，不打断你的判断。

04 / 纸账本

长得像一本账本

米白横格纸、朱红页边、落章与翻页动效。所有交互都围绕「记账」本身，没有多余装饰。

怎么装

  1. 下载 APK 到手机
  2. 在文件管理器里点开，允许「安装未知应用」
  3. 首次打开会申请通知与存储权限，按需允许即可

数据保存在本机，卸载会清空；重装前请留意。目前只提供纸账本版，简约版暂不单独发布。
